# HR Attrition Analysis using Power BI

## Project Overview
This project analyzes employee attrition using Power BI. The dashboard helps understand employee turnover and identify patterns across different HR categories.

## Project Objective
The objective of this project is to analyze employee attrition and present key HR insights through an interactive dashboard.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX

## Key Performance Indicators (KPIs)
- Total Employees
- Total Salary
- Total Attrition 
- Average Employee Age
- Average Salary
- Attration Rate

## Analysis Performed
- Employee attrition by department
- Employee attrition by gender
- Job Satisfaction by Job Role
- Attration by Salary Slab
- Attration by YearAtCompany
- Attaration num by EducationField

## Key Learnings
- Data analysis and visualization using Power BI
- Creating KPI cards and charts
- Building an interactive HR dashboard
- Identifying patterns in employee attrition
